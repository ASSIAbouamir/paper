\section{Discussion \& Architectural Implications (RQ5)}
\label{sec:discussion}

\subsection{The Two Fundamental Regimes of Multi-Expert Fusion}
\label{sec:two_regimes}

Our empirical findings establish that multi-expert sequential recommendation bifurcates into two distinct regimes:
\begin{enumerate}[leftmargin=*]
    \item \textbf{Regime I: Consensus-Dominant Regime ($\%H \ge 75\%$):} When historical transitions are mature, both collaborative and semantic models exhibit complementary errors. Gating at the sequence level degrades top rankings through the \emph{Scalar Routing Bottleneck}. Here, conservative late fusion is essential.
    \item \textbf{Regime II: Polarized Specialist Regime ($\%H < 75\%$):} In early prefix stages ($L \le 5$) or domain-specific splits where single-expert competence is highly asymmetric, sequence-level routing successfully extracts specialist headroom ($+18.4\%$ at $L=5$).
\end{enumerate}

\subsection{Cascaded Exception-Gating Architecture}
\label{sec:cascaded_arch}

To resolve the tension between general non-consensus detection and directional expert identification (\S\ref{sec:signatures}), we formalize a decoupled two-stage cascade:
\begin{enumerate}[leftmargin=*]
    \item \textbf{Stage 1 (Binary Non-Consensus Filter):} Conditions on collaborative entropy $H_c(u)$. If $H_c(u) \ge \tau_H$, the system defaults unconditionally to stationary geometric consensus ($0.5 \log P_C + 0.5 \log P_S$), protecting the consensus majority from perturbation.
    \item \textbf{Stage 2 (Candidate-Level Arbitration):} For low-entropy exception sequences ($H_c(u) < \tau_H$), arbitration is delegated to candidate-level disagreement scoring.
\end{enumerate}

\subsection{Resolution: Breaking Stationary Baselines via Adaptive CC-PoE}
\label{sec:cc_poe}

\subsubsection{Re-Centering Evaluation on Static Product-of-Experts}
The primary baseline in dual-expert recommendation must not be weak probability blending ($0.0641$), but \textbf{Static Logit Product-of-Experts (PoE)}:
\begin{equation}
    S_{\text{PoE}}(u, i) = 0.5 \log P_C(i \mid u) + 0.5 \log P_S(i \mid u)
\end{equation}
Moving from arithmetic averaging to geometric consensus immediately improves test $\text{HR@10}$ from $0.0641 \to 0.0725$ (+13.18\%, Table~\ref{tab:poe_benchmark}).

\subsubsection{Mathematical Formulation of CC-PoE}
Adaptive Consensus-Constrained Product-of-Experts (CC-PoE) scores item $i$ for user $u$ via:
\begin{equation}
    S(u, i) = \underbrace{(0.5 + \delta(\mathbf{x}_u)) \log P_C(i) + (0.5 - \delta(\mathbf{x}_u)) \log P_S(i)}_{\text{Base Geometric Consensus}} - \underbrace{\lambda(\mathbf{x}_u) \cdot |\log P_C(i) - \log P_S(i)|}_{\text{Adaptive Disagreement Penalty}}
\end{equation}
Letting $d(u, i) \triangleq \log P_C(i) - \log P_S(i)$, this corresponds to a piecewise candidate-level gate:
\begin{equation}
    S(u, i) = \begin{cases} 
    (0.5 + \delta - \lambda) \log P_C(i) + (0.5 - \delta + \lambda) \log P_S(i) & \text{if } d(u, i) > 0 \\
    (0.5 + \delta + \lambda) \log P_C(i) + (0.5 - \delta - \lambda) \log P_S(i) & \text{if } d(u, i) < 0 
    \end{cases}
\end{equation}
The 2-layer MLP parameterizes $\delta(\mathbf{x}_u) = 0.10 \tanh(\text{out}_0)$ and $\lambda(\mathbf{x}_u) = 0.34 \sigma(\text{out}_1)$ with exactly \textbf{578 parameters} ($448 + 64 + 66$), representing a negligible $0.03\%$ overhead ($+0.0073$ ms/user incremental latency).

\subsubsection{A Priori Theoretical Positivity Guarantee}
To guarantee that candidate scoring coefficients remain positive across all inputs:
\begin{equation}
    |\delta(\mathbf{x}_u)| \le 0.10, \quad \lambda(\mathbf{x}_u) \le 0.34 \implies \delta_{\max} + \lambda_{\max} = 0.44 < 0.50
\end{equation}
Therefore, for all users $u$ and candidates $i$:
\begin{equation}
    \min \big(0.5 \pm \delta(\mathbf{x}_u) - \lambda(\mathbf{x}_u)\big) \ge 0.50 - 0.44 = \mathbf{0.06} > 0
\end{equation}
guaranteeing positive expert weights \emph{a priori} across the entire input domain.

\subsubsection{Key Insights on Candidate Adaptation}
As shown in Table~\ref{tab:candidate_baselines} and Table~\ref{tab:seed_breakdown}:
\begin{enumerate}[leftmargin=*]
    \item \textbf{CC-PoE improves over Static PoE on every seed} ($+14$ to $+24$ hits, mean $+18.0$ hits, Table~\ref{tab:seed_breakdown}).
    \item \textbf{Occam's Principle in Late Fusion:} The unlearned, zero-parameter Fixed Disagreement PoE ($\lambda = 0.21$, HR@10 $= 0.0745$) captures two-thirds of the total gain ($+12$ net hits). Adaptive CC-PoE adds an incremental $+6$ hits over this fixed heuristic ($p = 0.20$ vs. fixed). Consistent with Occam's razor, the primary contribution lies in the \emph{geometric disagreement penalty principle} rather than complex neural parameterization.
    \item \textbf{Unconstrained Gating Overfits:} Black-box Candidate Linear Gate collapses to $0.0574$, and Item-Wise MLP barely matches Static PoE ($0.0734$), proving that candidate-level modulation requires an explicit consensus-constrained inductive bias.
\end{enumerate}
